# 📝 便签 MyNotes

> 一款美观可定制的 Windows 桌面便签工具：随手记录、高效管理待办、一键整理分类。
> 数据保存在本机，无需联网，隐私安全；支持自动更新，持续改进。

## ✨ 功能特点

### 🪟 窗口与贴靠

- **智能贴靠**：把窗口拖到屏幕边缘自动调整大小（顶部最大化、左右半屏、四角四分屏），并支持 Win11 贴靠布局选择，像系统一样高效分屏
- **顶栏亚克力模糊**：开启后主顶栏呈现毛玻璃质感，可自定义底色与透明度
- **统一窗口按钮**：右上角最小化 / 最大化 / 关闭按钮与顶栏样式融为一体

### 🗒️ 记录与整理

- **多视图**：便签画布、备忘录列表、待办区、文档视图，一键切换
- **两种记录类型**：普通笔记与待办清单（带勾选框）
- **分组管理**：创建、重命名、删除分组，用颜色区分归类
- **一键搜索**：输入关键词快速定位任意便签
- **智能排序**：自定义顺序 / 更新时间 / 创建时间 / 标题 / 颜色
- **便签个性化**：15 种便签颜色、自定义文字颜色、便签独立字体
- **批量选中**：顶栏「批量选中」进入多选，点击便签切换选中；支持批量删除、移动到分组、拖动任意已选便签整组移动，批量栏跟随顶栏外观
- **文本对齐**：右键菜单对选中内容一键左 / 居中 / 右对齐（`Ctrl+L` / `Ctrl+E` / `Ctrl+R`）；图片也可独立对齐
- **备忘录拖动排序**：列表内直接拖拽调整上下顺序
- **画布缩放 / 平移**：`Ctrl+滚轮`以光标为锚缩放、`空格或鼠标中键`拖动平移，右下角工具栏一键恢复 100%
- **便签框选**：空白处拖框即可多选，配合批量删除 / 移动到分组 / 整组拖动，比逐张点选更高效
- **分组折叠 / 展开**：折叠可把整组便签收起来，取消折叠精确恢复到折叠前布局（快照式可逆）
- **最近使用分组**：常用分组自动置顶，快速切换
- **空白画布右键快捷插入**：右键新建便签 / 新建待办 / 粘贴文本为新便签 / 一键整理
- **撤销 / 重做**：新建、删除、移动、缩放、分组等结构操作均可撤销重做（`Ctrl+Z` / `Ctrl+Shift+Z`）
- **便签归档 / 置灰**：归档便签移出常规视图，提供独立「归档」入口查看与恢复，归档卡自动置灰

### 📊 表格

- **自研轻量表格**：无需外部库，便签内直接插入表格
- **单元格操作**：插入 / 删除 / 合并 / 拆分单元格
- **斜线表头**：两种斜线方向，可分别编辑斜线两侧文字
- **样式自定义**：右键设置边框颜色、边框粗细、文字大小与文字颜色预设
- **编辑体验**：双击单元格即可编辑，支持单元格内换行

### 📄 文档模式

- **文档式阅读编辑**：让便签像文档一样排版查看与编辑，支持 Markdown
- **Markdown 快捷输入**：`Ctrl+B` 加粗、`Ctrl+H` 高亮，所见即所得
- **文本对齐**：左 / 居中 / 右对齐（工具栏按钮，或 `Ctrl+L` / `Ctrl+E` / `Ctrl+R`）
- **编辑时 Ctrl+滚轮**：快捷放大 / 缩小正文字号
- **Markdown 预览**：一键切换为只读预览，直接看到加粗、高亮、图片、表格等渲染效果

### 🖥️ 桌面集成

- **常驻系统托盘**：最小化不占任务栏，点击托盘图标快速显示 / 隐藏
- **钉在桌面**：把便签变成置顶的独立小窗口，始终可见
- **桌面亚克力玻璃**：钉在桌面的便签可启用 Windows 亚克力模糊效果（磨砂玻璃质感）
- **桌面右键菜单**：钉桌面后右键唤出快捷菜单，集成常用操作与透明度调节
- **窗口置顶**：一键让主窗口悬浮在其他窗口之上
- **透明度调节**：窗口与便签透明度随意调整
- **全局快捷键**：`Ctrl + Shift + N` 随时随地新建便签
- **单实例运行**：重复启动自动聚焦已有窗口

### ⏰ 定时提醒

- 为便签或待办设置提醒时间，到点弹出系统通知，主窗口闪烁提示
- **闹铃声音**：提醒时可播放声音，声音文件与音量可自定义，电脑待机也能保证提醒
- **稍后再响**：闹铃可延后 5 / 10 / 30 分钟再次提醒

### 🎨 外观定制

- **12 款预设主题**（薄荷默认置顶）+ 自定义主题，深浅色自由切换
- **明暗模式**：跟随主题 / 浅色 / 深色
- **强调色**：10 种预设色 + 自定义取色
- **画布背景**：纯色或本地图片，支持填充 / 适应 / 拉伸 / 平铺 / 居中
- **顶栏与背景透明度**：细节随心调整
- **高对比度优化**：开启亚克力模糊后按钮依然清晰可读
- **便签外观自定义**：圆角、阴影、边框粗细与颜色、字体字距，实时作用于所有便签卡片
- **右键菜单亚克力 + 透明度**：右键菜单可开启磨砂玻璃并调节透明度，与主题统一

### 🖼️ 富媒体

- **插入图片**：粘贴、选择本地图片，按光标位置放置，拖拽调整大小
- **拖入文件 / 文件夹**：粘贴路径自动识别，文件夹一键跳转、文件快速打开
- **部分选取改色**：选中便签内的文字局部改色，未选中则整篇生效
- **自定义字体**：导入 `.ttf` / `.otf` / `.woff` 字体文件

### 💾 数据管理

- **数据安全加固**：原子写入、版本号管理与损坏自动回退（`.bak`），断电也不怕数据写坏
- **备份自包含**：一键备份导出为文件夹包，自动携带图片 / 字体 / 声音等媒体文件，跨设备迁移不断图
- **导入备份**：快速恢复或迁移数据，自动还原备份里附带的媒体文件
- **导出 Markdown**：便签可导出为 Markdown（标题 / 加粗 / 高亮 / 表格 / 清单 / 文件链接），图片以 base64 内嵌为自包含单文件
- **媒体健壮性**：图片等媒体缺失时显示友好占位提示，可一键移除，不再破图
- **回收站**：删除的便签可恢复，超期自动彻底清理
- **本地存储**：数据保存在用户目录，无需联网，隐私安全

### 🌐 更多

- **中英双语**：简体中文 / English 一键切换
- **一键整理**：自动排列画布上的便签
- **开机自启动**：设置内一键开启，登录 Windows 后自动启动便签（默认关闭）
- **剪贴板**：便签内与标题均可正常复制 / 粘贴文字与图片，粘贴自动识别图片 / 文件路径
- **检查更新**：「关于」页可手动检查新版本，自动更新走弹窗下载 + 重启安装
- **关于页**：查看版本号、作者、开源地址与完整更新说明
- **快捷键系统**：全局唤起 / 新建 + 编辑器快捷键均可在设置内改键与恢复默认（含撤销 / 重做）
- **标签建议**：按笔记内容在「添加到分组」里自动推荐最合适的分组

## 📥 安装与使用

- 下载并运行 `MyNotes-Setup-*.exe` 安装包即可使用，**无需安装任何环境**；支持选择安装目录与创建桌面快捷方式。
- 数据保存在本机用户目录（无需联网），首次启动会展示更新说明。
- 在设置（⚙，右上角）里可自定义主题、画布背景、字体、提醒、语言、开机自启动等。

## 🔧 开发者

> 以下供参与开发 / 构建参考，日常使用无需理会。

**环境**：Windows + Node.js（本项目为 Electron 应用，端到端测试用 Playwright）。

```bash
npm install          # 安装依赖
npm start            # 本地运行
npm test             # 单元测试（Node 内置框架）
npm run test:e2e     # 端到端测试（Playwright）
npm run dist         # 打包生成安装包（输出到 release/）
npm run dist:publish # 打包并上传到 GitHub Releases（需 GH_TOKEN）
```

- **技术栈**：Electron 33 · electron-builder 25 · electron-updater 6 · Playwright · 原生 HTML / CSS / JS
- **版本管理**：仅改 `package.json` 的 `version`，应用内由 `app.getVersion()` 统一注入。
- **自动更新**：经 `electron-updater` 接通 GitHub Releases（`package.json` 的 `build.publish` 已配好）。
- **代码签名**：设 `CSC_LINK`（证书路径/base64）与 `CSC_KEY_PASSWORD` 即自动签名；正式分发建议 OV / EV 证书或 Azure Trusted Signing（未签时会触发 SmartScreen「未知发布者」）。
