# 📝 便签 MyNotes

> 美观可定制的 Windows 桌面便签工具，帮你随手记录、高效管理待办。
> 一个用于学习 Electron 的练手项目，功能持续完善中。

## ✨ 功能特点

### 🪟 窗口与贴靠

- **智能贴靠**：把窗口拖到屏幕边缘自动调整大小（顶部最大化、左右半屏、四角四分屏），像系统一样高效分屏
- **顶栏亚克力模糊**：开启后主顶栏呈现毛玻璃质感，可自定义底色与透明度
- **统一窗口按钮**：右上角最小化 / 最大化 / 关闭按钮与顶栏样式融为一体

### 🗒️ 记录与整理

- **三种视图**：便签画布、备忘录列表、待办区，一键切换
- **两种记录类型**：普通笔记与待办清单（带勾选框）
- **分组管理**：创建、重命名、删除分组，用颜色区分归类
- **一键搜索**：输入关键词快速定位任意便签
- **智能排序**：自定义顺序 / 更新时间 / 创建时间 / 标题 / 颜色
- **便签个性化**：15 种便签颜色、自定义文字颜色、便签独立字体
- **备忘录拖动排序**：列表内直接拖拽调整上下顺序

### 📊 表格

- **自研轻量表格**：无需外部库，便签内直接插入表格
- **单元格操作**：插入 / 删除 / 合并 / 拆分单元格
- **斜线表头**：两种斜线方向，可分别编辑斜线两侧文字
- **样式自定义**：右键设置边框颜色、边框粗细、文字大小与文字颜色预设
- **编辑体验**：双击单元格即可编辑，支持单元格内换行

### 📄 文档模式

- **文档式阅读编辑**：让便签像文档一样排版查看与编辑，支持 Markdown
- **Markdown 快捷输入**：`Ctrl+B` 加粗、`Ctrl+H` 高亮，所见即所得
- **编辑时 Ctrl+滚轮**：快捷放大 / 缩小正文字号

### 🖥️ 桌面集成

- **常驻系统托盘**：最小化不占任务栏，点击托盘图标快速显示 / 隐藏
- **钉在桌面**：把便签变成置顶的独立小窗口，始终可见
- **桌面亚克力玻璃**：钉在桌面的便签可启用 Windows 亚克力模糊效果
- **桌面右键菜单**：钉桌面后右键唤出快捷菜单，集成常用操作与透明度调节
- **窗口置顶**：一键让主窗口悬浮在其他窗口之上
- **透明度调节**：窗口与便签透明度随意调整
- **全局快捷键**：`Ctrl + Shift + N` 随时随地新建便签
- **单实例运行**：重复启动自动聚焦已有窗口

### ⏰ 定时提醒

- 为便签或待办设置提醒时间，到点弹出系统通知，主窗口闪烁提示
- **闹铃声音**：提醒时可播放声音，声音文件与音量可自定义，电脑待机也能保证提醒

### 🎨 外观定制

- **12 款预设主题**（薄荷默认置顶）+ 自定义主题，深浅色自由切换
- **明暗模式**：跟随主题 / 浅色 / 深色
- **强调色**：10 种预设色 + 自定义取色
- **画布背景**：纯色或本地图片，支持填充 / 适应 / 拉伸 / 平铺 / 居中
- **顶栏与背景透明度**：细节随心调整
- **高对比度优化**：开启亚克力模糊后按钮依然清晰可读

### 🖼️ 富媒体

- **插入图片**：粘贴、选择本地图片，按光标位置放置，拖拽调整大小
- **拖入文件 / 文件夹**：粘贴路径自动识别，文件夹一键跳转、文件快速打开
- **部分选取改色**：选中便签内的文字局部改色，未选中则整篇生效
- **自定义字体**：导入 `.ttf` / `.otf` / `.woff` 字体文件

### 💾 数据管理

- **一键备份**：导出到指定文件夹，随时打开备份目录
- **导入备份**：快速恢复或迁移数据
- **回收站**：删除的便签可恢复，超期自动彻底清理
- **本地存储**：数据保存在用户目录，无需联网，隐私安全

### 🌐 更多

- **中英双语**：简体中文 / English 一键切换
- **一键整理**：自动排列画布上的便签
- **剪贴板**：复制 / 粘贴文字与图片
- **关于页**：查看版本号、作者与完整更新说明

## 🚀 快速开始

### 环境要求

- Windows 系统
- Node.js（仅开发与构建时需要）

### 运行（开发）

```bash
npm install
npm start
```

### 打包（生成安装包）

```bash
npm run dist
```

> 打包产物位于 `release/` 目录，NSIS 安装包支持选择安装目录与创建桌面快捷方式。
