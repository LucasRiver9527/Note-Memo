# 桌面便签
新人练手的一个项目

桌面便签工具主要特点

常驻系统托盘：最小化后不占任务栏，点击托盘图标或使用快捷键 Cmd/Ctrl+Shift+N 快速显示/隐藏主窗口或新建便签。

定时提醒：可为每条便签设置提醒时间，到时弹出系统通知，主窗口会闪烁提示，确保你不会忘记重要事项。

桌面独立便签：可将任意便签“钉”在桌面上，以独立小窗口置顶显示，始终可见，适合作为临时备忘或待办清单。

窗口置顶与透明度调节：主窗口支持置顶，并可调整透明度，方便与其他应用搭配使用。

两种记录模式：支持普通笔记和待办清单（带勾选框）两种类型，满足不同记录需求。

自定义背景：允许用户选择本地图片作为便签背景，个性化视觉效果。

数据导入导出：支持将全部数据导出为 JSON 或纯文本备份，也可导入之前备份的 JSON 文件，便于迁移或恢复。

数据本地存储：所有数据保存在用户目录下，无需联网，隐私安全。

单实例运行：程序只允许一个主窗口，再次打开会激活已有窗口，避免重复启动。

全局快捷键：注册系统级快捷键，任何界面下都能快速新建便签。
